# AIG Group - Arco Iris Group S.A.

Landing page institucional para **Arco Iris Group S.A.**, empresa importadora y gestora de comercio internacional radicada en la República del Paraguay.

## 🚀 Características

- **Diseño Institucional Profesional**: Paleta de colores corporativa (azul marino #001f5c y verde lima #a4ff00)
- **Secciones Completas**:
  - Hero con portada de Paraguay
  - Misión y Visión
  - Servicios integrados
  - Infraestructura corporativa
  - Liderazgo ejecutivo
  - Sumate a nuestro equipo (AIG DRIVERS y AIG CLEANING)
  - Formulario de contacto funcional
  - Footer con información corporativa

- **Formularios de Postulación**:
  - AIG DRIVERS: Para conductores profesionales de logística
  - AIG CLEANING: Para personal de servicios de limpieza

- **Contacto Directo**: Formulario que envía mensajes a javierfernandosciolla@gmail.com

## 🛠️ Tecnología

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Routing**: Wouter

## 📦 Instalación

```bash
# Instalar dependencias
pnpm install

# Ejecutar en desarrollo
pnpm dev

# Construir para producción
pnpm build

# Preview de producción
pnpm preview
```

## 🌐 Despliegue en Netlify

1. Conecta este repositorio a Netlify
2. Configura los siguientes parámetros:
   - **Build command**: `pnpm build`
   - **Publish directory**: `dist`
   - **Node version**: 22.13.0

3. Netlify construirá y desplegará automáticamente
